# ArduinoRTC
ArduinoにRTCを接続する場合，ICの型番や製造メーカーが異なると，デバイスドライバのAPIが違いすぎ，複数のRTCをサポートする
統一的なプログラムを作るのが困難であるため，統一的なデバイスドライバのAPIとそのAPIに合わせたデバイスドライバ，
統一APIを使う便利なライブラリやアプリケーション集

## API

- [RTC_U](https://github.com/ArduinoRTC/RTC_U)



## ライブラリ

- [RTC_Utils](https://github.com/ArduinoRTC/RTC_Utils) : RTCのICの種別によるソースコードの違いを吸収するためのライブラリ
